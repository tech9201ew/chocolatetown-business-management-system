# Chocolatetown Business Management System (CBMS) - System Analysis & SRS

## Overview
This repository contains the complete Software Requirements Specification (SRS) for the **Chocolatetown Business Management System (CBMS)**, developed as a team project for SYD466 (Winter 2026)[cite: 3]. 

CBMS is designed to centralize and secure fragmented business operations for Chocolatetown, streamlining staff payroll, customer profiles, catering orders, supplier transactions, and financial invoicing[cite: 3].

## 🛠️ Project Scope & Key Features
* **Payroll & Staff Management:** Secure staff registration and payment tracking[cite: 3].
* **Customer & Order Management:** Centralized customer profiles and catering order lifecycles (Pending $\rightarrow$ Confirmed $\rightarrow$ Delivered)[cite: 3].
* **Financial Invoicing:** Automated calculation of subtotals and taxes, linking payments directly to invoices[cite: 3].
* **Supplier Transactions:** Inventory supply tracking, invoice uploads, and payment management[cite: 3].
